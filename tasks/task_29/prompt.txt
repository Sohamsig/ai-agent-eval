# Task 29 — Repository Investigation + Multi-file Feature

You are working on a small Python order-processing repository.

Your task is to investigate the existing implementation and improve
the order creation functionality.

Requirements:

1. Inspect actual_task_file.py and helpers.py before making changes.
2. create_order() must correctly calculate the total price.
3. Each item contains:
   - name
   - price
   - quantity
4. Quantity must be included when calculating the total.
5. Invalid items should be handled safely.
6. Discount percentages must be handled correctly.
7. Do not remove existing functionality.
8. Add meaningful tests for the changes.
9. Run the test suite after making your changes.
10. Do not simply replace the existing tests with new tests.

The goal is to demonstrate repository investigation,
multi-file reasoning, implementation, and verification.
